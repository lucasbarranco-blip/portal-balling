Guardar entre computadoras

Sin base, los cambios quedan en este navegador. Conectá una y el estado se comparte.

1
Creá un proyecto gratis en console.firebase.google.com y activá Firestore Database en modo producción.
2
En Reglas, pegá esto y publicá:
rules_version = '2'; service cloud.firestore { match /databases/{db}/documents { match /estado/{doc} { allow read, write: if true; } } }
3
En Configuración del proyecto → General copiá el ID del proyecto y la Clave de API web, y pegalos acá abajo.
La clave web es pública por diseño. Aun así, este portal es de uso interno: no publiques el link fuera de tus mayoristas. Firestore no pausa proyectos por inactividad, y sin tarjeta cargada nunca puede generar un cobro.
Mudar de cuenta Bajá una copia, conectá la base nueva y volvé a subirla. No se pierde nada.

Carga masiva de stock

Descargá la planilla, editá la columna Stock en Excel y pegá todo acá. También podés escribir a mano.

Formato: SKU · talle · cantidad. Acepta punto y coma, coma, tabulación o espacios, y descarta la fila de encabezado. Si el producto tiene un solo talle podés omitirlo.

Carga rápida por SKU

Pegá tu planilla o escribí una línea por producto. Se valida contra stock al instante.

Formato: SKU · talle · cantidad, separados por coma, punto y coma, tabulación o espacios. Si el producto tiene un solo talle podés omitirlo.
